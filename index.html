Progress Bar (Reactive)

How it works: The progress value is managed by a reactive state variable using useState. When you click the buttons, the state is updated using the setter function. The subscribe function populates subscribers object which is iterated over on value update, and updates the value attribute of the progress bar in real time. This demonstrates attribute binding and state-driven UI updates.
Functionality used: useState for state, subscribe for DOM updates, and direct attribute binding.

Todo List (Reactive)

How it works: The todo list is managed as an array in a reactive state variable. Adding a new todo updates the state, and the UI list is re-rendered automatically. Clicking a todo item removes it from the list by updating the state. This demonstrates dynamic list rendering and state-driven DOM updates.
    Functionality used: useState for array state, subscribe for list rendering, and event handlers for state updates.

    Attribute Binding Demo

    How it works: The input's value is stored in a reactive state variable. The Submit button is enabled only when the input is not empty, by binding the disabled attribute to the state. When you type, the state updates and the button's enabled/disabled state changes automatically. Clicking Submit shows the value and clears the input.
    Functionality used: useState for input state, subscribe for attribute binding, and event handlers for state updates.
